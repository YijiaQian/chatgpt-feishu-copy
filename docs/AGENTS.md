# 文档维护

README 面向使用者，说明当前能力、安装、操作与限制。开发命令和手动验收步骤归 [CONTRIBUTING](../CONTRIBUTING.md)，工具职责归 [维护检查](maintenance.zh-CN.md)。本目录入口为 [README](README.md)。

[PRD](PRD.zh-CN.md) 解释产品与架构，[会话导出](conversation-export.zh-CN.md) 解释该功能的设计与验收。历史验证归 [验证历史](validation-history.zh-CN.md)、具体版本验收或商店更新记录；不能根据当前代码改写当时观测。商店状态有日期，只在实际核实后更新。

长期设计理由归 `.agents/notes/`；临时计划、输出与诊断归被 Git 忽略的 `work/`。改标题、搬内容时修复导航、入链和锚点，先保留独有事实再缩减原页。任何检查通过都不能替代真实 ChatGPT → 飞书验收。
