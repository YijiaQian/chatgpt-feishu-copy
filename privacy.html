隐私说明

更新日期：2026-10-20。本说明适用于 Microsoft Edge 和 Google Chrome 中的「ChatGPT → 飞书 · 公式图片复制」扩展。

处理哪些内容

扩展在 ChatGPT 网页中识别回复和复制按钮。点击增强复制或文档导出图标后，读取所选回复的文字、公式、表格、图片地址、图标及可读取的图表，在本机生成适合飞书的富文本。转换工具也处理你主动粘贴的 Markdown 和主动选择的本地图片。它不读取无关网页或浏览历史。

点击“导出当前会话到本地”后，扩展会自动滚动当前会话，读取当前分支中的用户消息和 ChatGPT 回复，并在本机生成离线 HTML。文件包含消息文字、来源会话地址、可读取图片、公式显示所需的本地字体与脚本，以及复制到飞书的按钮；不会批量读取其他会话或隐藏的历史分支。

数据去向

文本解析、公式渲染和图片转换在本机完成；没有开发者收集服务器、广告、分析统计或遥测。为嵌入远程图片，浏览器会向图片原地址发起请求，服务器可能收到 IP 地址和请求信息；ChatGPT 同源图片请求可能带上现有登录会话，扩展不读取或保存密码、令牌或 Cookie 值。第三方 HTTPS 图片域名只在你主动授权后由扩展后台访问，网页预览也可能直接加载 Markdown 内的远程图片。

复制后，富文本和纯文本写入系统剪贴板，其他有权限的应用可访问。按 Ctrl+V 粘贴到飞书时，由飞书自身接收内容并上传图片，遵循飞书的隐私政策。导出 HTML 会把内容保存到你选择的本地文件。

本地保存与删除

扩展存储中仅保存功能开关，以及最近一次复制和导出的时间、数量统计和转换警告。警告可能包含图片说明、附件名称、相关域名或出错公式片段；不会在扩展存储中保存完整正文、图片或 Markdown 草稿。导出会把所选会话内容写入用户主动要求的本地文件，该文件不依赖 ChatGPT 登录即可阅读，请按需要自行保存和分享。新的操作记录会覆盖同类上次记录；卸载扩展可清除扩展本地存储和授权。剪贴板、导出文件、目标飞书文档以及浏览器自身缓存不随卸载删除，需要分别清理。

控制方式

可以关闭增强复制或图片嵌入，按住 Alt 点击原复制按钮使用原始复制，在浏览器扩展设置中限制网站访问、撤销授权或卸载扩展。分享问题截图、日志或 GitHub Issue 前，请删除个人内容；公开 Issue 由 GitHub 托管并适用其政策。

用途与联系

本扩展仅为用户主动要求的复制转换功能处理这些数据，不出售数据，不用于广告画像，也不用于模型训练。本项目是独立工具，与 OpenAI、飞书或 Microsoft 没有隶属或官方合作关系。隐私问题可通过开源仓库的 Issues 联系维护者，请勿提交密码、令牌或私密对话。本说明与实际功能同步更新。
